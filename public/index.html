Node dev server / backend

See the calls your loaders or BFF make to the backend: start the process with the DevScope hook preloaded — nothing to add to the repo.

NODE_OPTIONS="--import $HOME/.devscope/devscope-node.mjs" npm run dev

Missing module error? DevScope writes that file when it starts; you can also fetch it: curl -fsSL http://localhost:8765/node/devscope-node.mjs --create-dirs -o ~/.devscope/devscope-node.mjs
